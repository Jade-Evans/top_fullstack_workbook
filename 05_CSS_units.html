  • In CSS, units define the size or length of many properties, including fonts, spacing, layout, and more.
  • These Units fall into two categories:
    1. Absolute Units:The size of an absolute unit is fixed will not change in relation to anything else on the page. In web development, px is really the only absolute unit we should be using (others like inch or cm are more relevant for printing).
    2. Relative Units: The size of an element defined with a relative unit can change in relation to other elements on the page, such as the root element or an element's parent.
  • Types of relative units:
    Unit Relative To Description Value/Data Type
    em the size of the element or parent 1em is equal to the font size, so i.e. if the font size is of the parent is 12px and the em is 4em the font size would be 48px <length>
    rem root or html font size This is recommended, as it works the same as the above without having to keep track of parent element sizes, so is more predictable.
    vw the viewport width. 1vw = 1% of the viewport width.
    vh the viewport height. 1vh = 1% of the viewport height.

rems vs ems

The image on the left is useful for showing the difference between em and rem relative units. Both pieces are code are the same except for the use of em on the first example, and rem on the second. As em is relative to its parent, it will get progressively bigger each time. Rem, on the other hand, remains relative to the root/html font size throughout, so the sizing is consistent regardless of the degree of parent/child.

Numbers, Lengths & Percentages

A table summarising some key data types in CSS:
Data Type Description Example Category
<integer> Any whole number 56, 1209, -89, -3 Numbers, Lengths or Percentages
<number> Refers to any number, which could include integers or numbers with decimals too. 56, 2.3, -99, -0.987 Numbers, Lengths or Percentages
<dimension> Refers to a number with a unit attached to it. Note: this is an umbrella term, encompassing data types like <length>, <angle>, <time> and <resolution> 0.3s, 45deg, 20px, 6in Numbers, Lengths or Percentages
<percentage> Refers to a percentage or fraction of a number; percentages are always relative to another quantity. 50%, 22% etc. Numbers, Lengths or Percentages
